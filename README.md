# ArchiNova AI

**From plan to vision.**

ArchiNova AI is an architectural visualization workspace for architects and designers. The goal is to let users upload plans, sketches or references, describe the visual direction they want, and create presentation-ready architectural concepts with AI.

## Current prototype

The first version includes:

- Responsive premium landing page
- Architectural brand system
- Upload flow for images and PDFs
- Image preview for uploaded references
- Project description / prompt field
- Architectural style presets
- Aspect-ratio selection
- Demo render interaction
- Mobile-first responsive layout

## Next phases

- Real AI image generation API
- Authentication
- Supabase project database and file storage
- Saved projects and render history
- Multiple render variations
- Credits / subscription system
- Client presentation exports
- Custom domain and production deployment
